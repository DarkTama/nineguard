Per ADR 0007/0008. Each API Key enforces one Quota Mode: Key Quota (one cumulative limit) or Model Quotas (one limit per exact Model, each with its own period). Sample data only. Colors: green < 80%, amber ≥ 80% (quota_warn_percent), red = exhausted.
